개인정보처리방침

HermesGoogleOath는 SeungWoo Han 본인이 자신의 Google 계정에 사용하는 개인용 연동 도구입니다.

접근하는 정보와 목적

사용자가 승인한 OAuth 권한에 따라 이메일과 첨부파일, 일정, Drive 파일, 문서, 스프레드시트, 연락처에 접근할 수 있습니다. 해당 정보는 사용자가 요청한 조회·요약·작성·발송·일정 관리·파일 및 문서 작업에 사용합니다.

처리 및 외부 서비스

연동 프로그램은 사용자의 컴퓨터에서 실행되며 Google API와 통신합니다. Hermes 사용 중 요청 내용과 필요한 Google 데이터 일부가 사용자가 설정한 AI 제공자 또는 메시징 서비스로 전달될 수 있습니다. 이 공개 사이트에는 Google 계정 데이터나 OAuth 인증정보를 게시하지 않습니다.

저장과 삭제

OAuth 토큰은 로컬 인증 파일에 보관됩니다. 작업 결과와 대화·실행 기록은 사용하는 Hermes 환경 및 연결된 서비스의 설정에 따라 남을 수 있습니다. 정해진 기간 후 자동 삭제된다고 보장하지 않으며, 삭제하려면 해당 로컬 파일·기록과 연결 서비스의 보관 데이터를 각각 관리해야 합니다. Google에 저장된 원본은 별도로 삭제하지 않는 한 유지됩니다.

제공·판매 및 AI 학습

Google 사용자 데이터를 판매하거나 광고 목적으로 사용하지 않습니다. Google API로 받은 데이터를 일반화된 AI·머신러닝 모델 학습용 데이터로 사용하지 않습니다. 외부 AI 제공자를 이용할 때에는 Google 사용자 데이터 정책에 맞는 데이터 처리 설정을 사용해야 합니다.

접근 철회

Google 계정의 연결 관리에서 이 앱의 접근을 철회할 수 있습니다. 철회는 이후 API 접근을 막지만, 이미 저장한 작업 결과나 대화 기록까지 자동 삭제하지는 않습니다.

Google API 정책

Google API에서 받은 정보의 사용 및 다른 앱으로의 전송은 Google API Services User Data Policy의 Limited Use 요건을 준수해야 합니다.

정적 사이트 호스팅

소개 및 방침 페이지는 GitHub Pages에 호스팅할 예정입니다. 이 페이지에는 별도 분석 스크립트나 입력 폼이 없으나, 호스팅 제공자는 서비스 운영을 위해 IP 주소 등 접속 정보를 처리할 수 있습니다. GitHub 개인정보처리방침이 적용됩니다.
